# CodeAlpha_Hangman

## Hangman Game

A simple interactive text-based Hangman Game developed using Python as part of my CodeAlpha Internship.

### Features
- Uses 5 predefined words
- Random word selection
- Guess one letter at a time
- Maximum 6 incorrect guesses
- Console-based gameplay

### Concepts Used
- Random module
- Strings
- Lists
- While loop
- If-else conditions
